# 003 - Data Types & I/O

Objectives

- Identify primitive data types and common operations on them.
- Read from and write to standard input/output and files.
- Choose appropriate types for variables and simple conversions.

Description

This session introduces primitive types (numbers, strings, booleans), basic operations, and common I/O patterns. Students will practice reading input, parsing values, and producing formatted output, plus safe conversion and simple validation. (36 words)

Outline

1. Primitive types and literals
2. Operations and type conversion
3. Input methods (stdin, input())
4. Formatting output and basic validation
5. Brief note on locales and encoding

Exercises

- Short coding exercise: Read two integers from input, compute and print their sum with a clear prompt.
- Mini-project: Create a small interactive program that asks for user data, validates it, and saves a summary to a text file.

Sample Code (Python)

```python
# sum_input.py
a = int(input('Enter first number: '))
b = int(input('Enter second number: '))
print(f'Sum: {a + b}')
```
