# Analýza výstupů programu (profiling)

Profilování pomáhá zjistit, kde program skutečně tráví čas a spotřebovává
prostředky. Místo odhadů používá měření a vede k cíleným úpravám kódu.

## Prerekvizity

- Funkce a práce s moduly.
- Základní práce se soubory a kolekcemi.
- Automatické testy a ověřování správnosti programu.

## Cíle

- Rozlišit měření času, benchmark a profilování.
- Měřit malé úseky kódu pomocí `timeit`.
- Najít nákladné funkce pomocí `cProfile` a číst statistiky `pstats`.
- Rozpoznat úzké hrdlo a navrhnout měřitelnou optimalizaci.
- Porovnávat varianty korektně a zachovat správnost programu.
