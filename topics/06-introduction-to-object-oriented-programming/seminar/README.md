# Seminář: Úvod do OOP

_Připravujeme._

Sem přijdou úlohy řešené společně na semináři k tématu [Úvod do objektově orientovaného programování](../README.md).


Objekty a základní principy Objektivně orientovaného programování (OOP) v Pythonu si projdeme tak, že si zadefinujeme třídy, vytvoříme objekty a porozumíme konstrukcím a základním OP konceptům. Toto téma je postaveno na znalosti funkcí a vyvinutějších struktur programů. 

Prerekvizity
-	Porozumění data typům, variables, podmínky a smyčky, funkce
-	Pochopení práce se základními moduly

Cíle
-	Pochopení, co to je objekt a jeho tvorba
-	Definování třídy (class)
-	Definování atribut
-	Porozumění self a __init__()

Klíčová slova
-	Object, class, attribute, constructor

Přednáška
-	Definice objektu, třídy, tvorba objektu
-	Přidělení atribut
-	Speciální metody: __init__()
-	Object attributes a self
-	Data store
-	(dědičnost, polymorfie, ...)
