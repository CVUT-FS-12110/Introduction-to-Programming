# Sdílené proměnné a komunikace mezi částmi programu

Větší program se skládá z částí, které si musí předávat data. Téma ukazuje,
jak volit mezi návratovými hodnotami, parametry, objekty a sdíleným stavem a
proč nekontrolované globální proměnné znesnadňují porozumění i testování.

## Prerekvizity

- Funkce, parametry, návratové hodnoty a rozsah platnosti proměnných.
- Mutabilní a imutabilní datové typy.
- Třídy, instance a atributy.
- Základní principy automatického testování.

## Cíle

- Vysvětlit lokální, globální a sdílený stav.
- Předávat data explicitně parametry a návratovými hodnotami.
- Předvídat důsledky sdílení mutabilního objektu.
- Vyhnout se mutabilním výchozím argumentům a skrytým závislostem.
- Zapouzdřit související stav a chování do objektu.
