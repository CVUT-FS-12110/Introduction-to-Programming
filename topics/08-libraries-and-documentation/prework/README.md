# Domácí příprava: průzkum knihoven na PyPI

Cílem je přijít na výuku s konkrétní zkušeností, jak se knihovna hledá
a podle čeho lze posoudit, zda je pro projekt použitelná.

## Úkol 1: pojmy

Vlastními slovy jednou větou vysvětlete:

- modul,
- balíček,
- knihovna,
- závislost,
- virtuální prostředí.

U každého pojmu si připravte jeden příklad. Pokud si významem nejste jistí,
poznamenejte si otázku k výkladu.

## Úkol 2: průzkum dvou knihoven

Na [PyPI](https://pypi.org/) najděte dvě knihovny, které vás zaujmou.
Pro každou si poznamenejte:

- co knihovna dělá,
- jak se instaluje,
- odkaz na její dokumentaci a zdrojový repozitář,
- podporované verze Pythonu,
- datum posledního vydání,
- licenci, pokud ji dokážete dohledat,
- jeden důvod, proč byste ji použili, a jedno možné riziko.

Jedna z knihoven musí mít alespoň krátký příklad použití v dokumentaci.
Knihovny zatím nemusíte instalovat.

## Úkol 3: čtení dokumentace

V dokumentaci jedné vybrané knihovny najděte:

1. instalační příkaz,
2. minimální spustitelný příklad,
3. popis jedné funkce nebo třídy,
4. informaci o tom, jak knihovna hlásí chyby.

Při společném průchodu stručně představíte, kde jste jednotlivé informace našli.
