# Přednáška: ukládání a serializace dat

- [Prezentace (PDF)](presentation.pdf)
- [Zdrojový soubor prezentace](presentation.tex)

Přednáška vysvětluje serializaci a deserializaci, mapování datových typů
v JSONu, tabulkový model CSV, obnovu typů, vnořená a relační data a základní
bezpečnostní omezení formátu pickle. Navazuje na práci se soubory,
výjimkami a moduly standardní knihovny.

Navazují na ni [komentované příklady](../seminar/seminar.md),
[domácí příprava](../prework/assignment.md) a
[samostatné cvičení](../lab/assignment.md).
