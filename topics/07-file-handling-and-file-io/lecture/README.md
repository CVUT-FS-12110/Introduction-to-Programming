# Přednáška: práce se soubory

- [Prezentace (PDF)](presentation.pdf)
- [Zdrojový soubor prezentace](presentation.tex)

Přednáška vysvětluje životní cyklus souboru, režimy otevření, bezpečné čtení
a zápis pomocí `with`, zpracování po řádcích, UTF-8, očekávatelné chyby,
práci s cestami pomocí `pathlib` a rozdíl mezi textovými a binárními daty.
Navazují na ni [komentované příklady](../seminar/seminar.md) a
[samostatné cvičení](../lab/assignment.md).
