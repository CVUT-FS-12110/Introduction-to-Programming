# Seminář: základní Git workflow

Na semináři se společně projde [zadání z domácí
přípravy](../prework/assignment.md). Jde o stejné zadání, studenti proto
nezačínají novou úlohu.

Vyučující při průchodu:

- okomentuje význam jednotlivých příkazů a stavů repozitáře,
- vysvětlí vztah mezi pracovním adresářem, stage a commity,
- ukáže práci s lokální a vzdálenou větví,
- podrobněji předvede vznik a řešení konfliktu,
- upozorní na časté chyby a bezpečné možnosti jejich opravy,
- ponechá prostor pro dotazy a porovnání různých postupů.

Studenti pracují se svým repozitářem z domácí přípravy. Pokud ji nedokončili,
navážou v místě, kde se zastavili.
